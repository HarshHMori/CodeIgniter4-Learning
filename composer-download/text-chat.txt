You previously had:

It is a focused Hindi CI4 routing lecture. ([YouTube][2])

### My recommendation:

If routing became clear from the 74-lesson playlist:

**Skip it.**

If routing still feels confusing:

**Watch the full single video.**

You should be able to create:

```php
$routes->get('/products', 'ProductController::index');

$routes->get(
    '/products/(:num)',
    'ProductController::show/$1'
);
```

And route groups:

```php
$routes->group('admin', function ($routes) {

    $routes->get('products', 'Admin\ProductController::index');

    $routes->get('orders', 'Admin\OrderController::index');

});
```

Modern CI4 4.7.4 also has **Auto Routing (Improved)**, so after learning regular defined routes, read its current documentation rather than depending entirely on an older video. ([CodeIgniter][3])

# 4. Filters + CSRF — watch separately

Here I **do recommend the extra focused lecture**.

Watch:

[▶ Honeypot & CSRF Filters](https://www.youtube.com/watch?v=bPVAkVNTCs0)

Watch the **whole video**.

Why?

Because Filters become important later for:

```text
Authentication
Authorization
CSRF
CORS
API protection
Admin protection
```

Current CodeIgniter 4.7.4 describes filters as code that can run **before or after controllers**, and they can be attached to specific routes. ([CodeIgniter][4])

Practice:

